# Nuevo Amanecer

Todos los archivos van en la raíz del repositorio (sin carpetas):
index.html, manifest.webmanifest, sw.js, vercel.json, xlsx.full.min.js,
icon-192.png, icon-512.png, maskable-512.png, apple-touch-icon.png.

Code.gs NO se sube a Vercel; es para pegar en Google Apps Script (puedes subirlo o no, no afecta).

Vercel: Framework Preset "Other", sin Build Command ni Output Directory.
Instalar: Android (Chrome) menú ⋮ → Instalar app. iPhone (Safari) Compartir → Agregar a pantalla de inicio.
Google Sheets: pega Code.gs en Extensiones → Apps Script, cambia CLAVE, implementa como Aplicación web (acceso: Cualquier persona) y pega la URL /exec y la clave en la app.
